# TCP vs UDP na Prática

Esse script demonstra como funcionam os dois principais protocolos de transporte da internet:

- TCP
- UDP

Eles são responsáveis por:
> transportar dados entre aplicações.

Exemplos:
- navegador
- jogos online
- chamadas de vídeo
- streaming
- SSH
- DNS

---

# Parte 1 — Teste TCP

## Criando um servidor TCP

```bash
nc -l -p 4444
```

### O que acontece

O `nc` (netcat):
- abre uma porta
- fica escutando conexões

Nesse caso:
- protocolo → TCP
- porta → `4444`

---

## Enviando dados

```bash
echo "Ola via TCP" | nc -w 1 localhost 4444
```

### O que acontece

O cliente:
- conecta ao servidor
- envia a mensagem
- encerra a conexão

---

# Por que o TCP é importante

TCP é um protocolo:
- confiável
- orientado à conexão
- garante entrega

Ele:
- verifica erros
- reenvia pacotes perdidos
- mantém a ordem correta

---

# Onde TCP é usado

| Serviço | Motivo |
|---|---|
| HTTP/HTTPS | páginas precisam chegar completas |
| SSH | comandos não podem falhar |
| FTP | arquivos precisam ser íntegros |
| Banco de dados | dados não podem ser perdidos |

---

# Fluxo do TCP

```text
Cliente
↓
abre conexão
↓
envia dados
↓
servidor confirma
↓
conexão encerrada
```

---

# Parte 2 — Teste UDP

## Criando servidor UDP

```bash
nc -u -l -p 5555
```

### O que acontece

Agora o `nc`:
- escuta usando UDP
- porta `5555`

---

## Enviando dados via UDP

```bash
echo "Ola via UDP" | nc -w 1 -u localhost 5555
```

### O que acontece

O cliente:
- envia o pacote
- não verifica confirmação
- não cria conexão real

---

# Por que o UDP é importante

UDP é:
- rápido
- leve
- sem confirmação

Ele NÃO:
- garante entrega
- garante ordem
- retransmite pacotes

---

# Onde UDP é usado

| Serviço | Motivo |
|---|---|
| Jogos online | velocidade é prioridade |
| Streaming | atraso é pior que perda |
| Chamadas VoIP | precisa ser instantâneo |
| DNS | consultas rápidas |

---

# Fluxo do UDP

```text
Cliente
↓
envia pacote
↓
fim
```

Sem confirmação.

---

# Diferença Principal

| TCP | UDP |
|---|---|
| Confiável | Rápido |
| Mais lento | Mais leve |
| Garante entrega | Não garante |
| Usa conexão | Sem conexão |
| Reenvia pacotes | Não reenvia |

---

# Por que aprender TCP e UDP é importante

Porque praticamente toda comunicação de rede usa um dos dois.

Quando você:
- acessa sites
- joga online
- faz chamadas
- usa APIs
- acessa servidores

o sistema está usando:
> TCP ou UDP.

Entender isso ajuda a:
- diagnosticar problemas
- entender latência
- analisar tráfego
- usar ferramentas de rede
- trabalhar com segurança ofensiva/defensiva
- compreender como aplicações funcionam
