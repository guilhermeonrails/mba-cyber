### Shebang

```bash
#!/bin/bash
```

* Define que o script deve ser executado usando o interpretador **Bash**.
* Garante consistência mesmo se o shell padrão do sistema for outro.

---

### Definição da função

```bash
organizar() {
```

* Declara uma função chamada `organizar`.
* Essa função será responsável por classificar e mover arquivos.

---

### Variável local

```bash
    local file="$1"
```

* Cria uma variável **local** chamada `file`.
* Recebe o primeiro argumento passado para a função (`$1`).
* O uso de `local` evita conflitos com variáveis globais.

---

### Verificação de arquivo regular

```bash
    [ -f "$file" ] || return
```

* `[ -f "$file" ]` verifica se o caminho é um **arquivo comum**.
* Se **não for**, o `|| return` faz a função encerrar imediatamente.
* Evita processar diretórios, links, etc.

---

### Extração da extensão

```bash
    ext="${file##*.}"
```

* Usa **expansão de parâmetros** do Bash.
* Remove tudo até o último `.` e mantém só a extensão.
* Exemplo: `arquivo.txt` → `txt`.

---

### Estrutura condicional `case`

```bash
    case "$ext" in
```

* Inicia um bloco de decisão baseado na extensão.

---

### Mapeamento de extensões → diretórios

Exemplo:

```bash
        csv) dir="csvs" ;;
```

* Se extensão for `csv`, define diretório `csvs`.

Outros casos seguem o mesmo padrão:

```bash
        pdf) dir="pdfs" ;;
        txt) dir="txts" ;;
        py)  dir="python" ;;
        rb)  dir="ruby" ;;
```

* Agrupamento por tipo de arquivo.

---

### Agrupamento de imagens

```bash
        png) dir="imagens" ;;
        jpg) dir="imagens" ;;
        jpeg) dir="imagens" ;;
        gif) dir="imagens" ;;
        bmp) dir="imagens" ;;
```

* Várias extensões apontam para o mesmo diretório `imagens`.

---

### Agrupamento de vídeos

```bash
        mp4) dir="videos" ;;
        mov) dir="videos" ;;
```

---

### Caso padrão

```bash
        *) return ;;
```

* Se a extensão não estiver listada:

  * A função termina sem fazer nada.

---

### Fim do `case`

```bash
    esac
```

---

### Criação do diretório

```bash
    mkdir -p "$dir"
```

* Cria o diretório se não existir.
* `-p` evita erro caso ele já exista.

---

### Movimentação do arquivo

```bash
    mv -n "$file" "$dir/" 2>/dev/null
```

* Move o arquivo para o diretório correspondente.
* `-n` (no-clobber):

  * Não sobrescreve arquivos existentes.
* `2>/dev/null`:

  * Descarta mensagens de erro (stderr).

---

### Log no terminal

```bash
    echo "[+] Movido: $file -> $dir/"
```

* Mostra uma mensagem indicando o arquivo movido.

---

### Fim da função

```bash
}
```

---

## Execução inicial

```bash
echo "[*] Organizando arquivos existentes..."
```

* Exibe mensagem informativa.

---

### Loop sobre arquivos atuais

```bash
for file in *; do
    organizar "$file"
done
```

* Percorre todos os itens no diretório atual (`*`).
* Chama a função `organizar` para cada item.

---

## Monitoramento em tempo real

```bash
echo "[*] Monitorando novos arquivos..."
```

---

### Uso do `inotifywait`

```bash
inotifywait -m -e close_write --format "%f" . |
```

* `inotifywait` monitora eventos no sistema de arquivos.
* `-m`: modo contínuo (monitoramento infinito).
* `-e close_write`: dispara quando um arquivo é fechado após escrita.
* `--format "%f"`: retorna apenas o nome do arquivo.
* `.`: diretório atual.

---

### Pipe para loop `while`

```bash
while IFS= read -r file
```

* Lê cada nome de arquivo emitido pelo `inotifywait`.
* `IFS=` evita remoção de espaços.
* `-r` evita interpretação de caracteres especiais (ex: `\`).

---

### Processamento contínuo

```bash
do
    organizar "$file"
done
```

* Para cada novo arquivo detectado:

  * Chama a função `organizar`.
