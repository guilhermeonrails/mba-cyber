# Resumo do Mapeamento da Rede

Essa saída mostra:
- suas interfaces de rede
- seu IP
- o gateway (roteador)
- como o Linux sabe para onde enviar os dados

---

# Interface principal

```text
eth0
```

Essa é sua conexão de rede ativa.

O status:

```text
state UP
```

significa:

> a rede está funcionando.

---

# Seu IP

```text
172.22.0.3/16
```

Esse é o endereço do seu computador dentro da rede.

O `/16` significa que sua rede é:

```text
172.22.x.x
```

---

# Gateway (Roteador)

```text
default via 172.22.0.1
```

Esse é o endereço do roteador/gateway.

Ele é:
- a saída da sua rede
- o caminho para a internet

Fluxo:

```text
Seu PC → Gateway → Internet
```

---

# Loopback (`lo`)

```text
127.0.0.1
```

Representa:
> o computador falando consigo mesmo.

Muito usado para testes locais.

---

# Interfaces extras

```text
tunl0
gre0
sit0
```

São interfaces especiais:
- VPN
- túneis
- redes avançadas

Como estão:

```text
state DOWN
```

elas não estão sendo usadas.

---

# Tabela de roteamento

Mostra:
> para onde os pacotes devem ir.

Exemplo:

```text
172.22.0.0/16 dev eth0
```

Significa:
> dispositivos `172.22.x.x` estão na mesma rede local.

---

# Principais conceitos

| Termo | Significado |
|---|---|
| IP | Endereço do computador |
| Gateway | Saída para internet |
| Interface | Porta de rede |
| MAC | Identidade física da placa |
| Roteamento | Caminho dos dados |

---

# Comandos importantes

## Ver IP

```bash
ip addr
```

## Ver rotas

```bash
ip route
```

## Testar internet

```bash
ping 8.8.8.8
```

## Escanear rede

```bash
nmap 172.22.0.0/16
```
