# Explicação da Saída de Rede

```text
1: lo: <LOOPBACK,UP,LOWER_UP>
```

- `lo` → interface de loopback
- usada para o computador falar consigo mesmo
- `UP` → interface ativa

---

```text
mtu 65536
```

- MTU = tamanho máximo do pacote
- loopback usa valor alto porque é comunicação interna

---

```text
inet 127.0.0.1/8
```

- IP local do próprio computador
- `127.0.0.1` sempre significa:
  > "esta máquina"

---

```text
inet6 ::1/128
```

- versão IPv6 do loopback

---

# Interfaces Virtuais/Túneis

```text
2: tunl0@NONE
3: gre0@NONE
4: gretap0@NONE
5: erspan0@NONE
6: ip_vti0@NONE
7: ip6_vti0@NONE
8: sit0@NONE
9: ip6tnl0@NONE
10: ip6gre0@NONE
```

Essas interfaces servem para:
- VPN
- encapsulamento
- túneis de rede
- IPv6
- redes avançadas

---

```text
state DOWN
```

- significa que estão desligadas
- não estão sendo usadas

---

```text
28: eth0@if29
```

- `eth0` → interface principal da rede
- responsável pela conexão real

---

```text
<BROADCAST,MULTICAST,UP,LOWER_UP>
```

- `UP` → interface ligada
- `LOWER_UP` → conexão física funcionando
- `BROADCAST` → consegue enviar para todos da rede
- `MULTICAST` → suporta envio para grupos

---

```text
mtu 1500
```

- tamanho padrão dos pacotes Ethernet

---

```text
state UP
```

- rede funcionando normalmente

---

```text
link/ether 02:42:ac:16:00:03
```

- endereço MAC da interface
- identificação física da placa de rede

---

```text
inet 172.22.0.3/16
```

- IP do computador na rede
- `/16` define o tamanho da rede

---

```text
brd 172.22.255.255
```

- endereço de broadcast
- usado para enviar mensagens para toda a rede

---

```text
scope global eth0
```

- IP válido para comunicação na rede

---

```text
valid_lft forever
```

- IP não possui tempo de expiração

---

# Tabela de Roteamento

```text
default via 172.22.0.1 dev eth0
```

- rota padrão da rede
- `172.22.0.1` é o gateway/roteador
- saída para internet

Fluxo:

```text
Seu PC → Gateway → Internet
```

---

```text
172.22.0.0/16 dev eth0
```

- define a rede local
- todos os IPs `172.22.x.x` pertencem à mesma rede

---

```text
src 172.22.0.3
```

- IP de origem usado pela interface

---

# Resumo Final

| Item | Significado |
|---|---|
| `lo` | Loopback |
| `127.0.0.1` | Próprio computador |
| `eth0` | Interface principal |
| `172.22.0.3` | Seu IP |
| `172.22.0.1` | Gateway/Roteador |
| `state UP` | Interface ativa |
| `MAC Address` | Identidade física |
| `Broadcast` | Mensagem para todos |
| `Tabela de Roteamento` | Caminhos da rede |
