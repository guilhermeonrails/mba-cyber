# Partes Mais Importantes da Saída

## 1. Interface de Rede Ativa

```text
eth0
```

Essa é a interface de rede principal do sistema.

Ela representa:
> sua conexão com a rede.

---

## 2. Estado da Interface

```text
state UP
```

Significa:
> a interface está ligada e funcionando.

---

## 3. Seu Endereço IP

```text
inet 172.22.0.3/16
```

Esse é o IP do seu computador na rede.

### Quebrando:
- `172.22.0.3` → IP do seu dispositivo
- `/16` → tamanho da rede

---

## 4. Gateway (Roteador)

```text
default via 172.22.0.1
```

Esse é o ponto MAIS importante da tabela de roteamento.

O gateway:
> é a saída para a internet.

Fluxo:

```text
Seu PC → Gateway → Internet
```

---

## 5. Rede Local

```text
172.22.0.0/16 dev eth0
```

Significa:
> qualquer IP começando com `172.22` pertence à mesma rede local.

---

## 6. Loopback

```text
127.0.0.1
```

Representa:
> o computador falando consigo mesmo.

Usado para:
- testes
- serviços locais
- desenvolvimento

---

## 7. Interfaces Extras

```text
tunl0
gre0
sit0
```

São interfaces especiais para:
- VPN
- túneis
- redes avançadas

Como estão:

```text
state DOWN
```

não estão sendo usadas.

---

# Resumo Geral

| Item | Significado |
|---|---|
| `eth0` | Interface principal |
| `172.22.0.3` | Seu IP |
| `172.22.0.1` | Gateway/Roteador |
| `state UP` | Rede funcionando |
| `127.0.0.1` | Próprio computador |
| `/16` | Tamanho da rede |
