# Explicação da Configuração de IP no Linux

A máscara de sub-rede, como o /24 (ou 255.255.255.0) do seu exemplo, é o que define qual parte de um endereço IP identifica a rede e qual parte identifica o dispositivo (host) específico dentro dessa rede. Ela funciona como um filtro: os bits marcados pela máscara dizem ao sistema que "esta vizinhança termina aqui", permitindo que o computador saiba se um destino está na mesma rede local ou se precisa enviar o pacote para um roteador (gateway) para alcançar uma rede externa. No caso do /24, os primeiros 24 bits (os três primeiros números do IP) são fixos para a rede, deixando os últimos 8 bits livres para endereçar até 254 aparelhos diferentes.

# Etapa 1 — Adicionando um IP

```text
Adicionando o IP 10.99.99.1/24 na interface lo
```

## Significado

Foi criado manualmente o IP:

```text
10.99.99.1
```

na interface:

```text
lo
```

(loopback)

---

## O que significa `/24`

Define o tamanho da rede.

Nesse caso:

```text
10.99.99.x
```

faz parte da mesma rede.

---

# Etapa 2 — Verificando a Interface

```text
1: lo: <LOOPBACK,UP,LOWER_UP>
```

## Significado

- `lo` → interface loopback
- usada para comunicação interna
- `UP` → interface ativa

---

```text
inet 127.0.0.1/8
```

## Significado

IP padrão do loopback.

Representa:
> o próprio computador

---

```text
inet 10.99.99.1/24 scope global lo
```

## Significado

O novo IP foi adicionado com sucesso.

Agora a interface `lo` possui:
- IP padrão → `127.0.0.1`
- IP adicional → `10.99.99.1`

---

```text
scope global
```

Indica que:
- o IP pode ser usado normalmente pelo sistema

---

# Etapa 3 — Testando com Ping

```text
PING 10.99.99.1
```

O sistema enviou pacotes para:
> ele mesmo

---

# Resposta do Ping

```text
64 bytes from 10.99.99.1
```

## Significado

O IP respondeu corretamente.

Isso prova que:
- o endereço está ativo
- a interface funciona
- o sistema consegue alcançar esse IP

---

```text
icmp_seq=1
icmp_seq=2
```

- sequência dos pacotes enviados

---

```text
ttl=64
```

TTL = Time To Live

Controla:
> quantos roteadores o pacote pode atravessar.

Como o pacote ficou local:
- TTL permaneceu alto

---

```text
time=0.053 ms
```

Tempo de resposta extremamente rápido.

Porque:
> a comunicação aconteceu dentro do próprio computador.

---

# Estatísticas do Ping

```text
2 packets transmitted, 2 received
```

## Significado

- 2 pacotes enviados
- 2 respostas recebidas

Conectividade funcionando perfeitamente.

---

```text
0% packet loss
```

## Significado

Nenhuma perda de pacotes.

---

```text
rtt min/avg/max
```

RTT = Round Trip Time

Mostra:
- menor tempo
- média
- maior tempo da comunicação

# Conceitos Importantes

| Termo | Significado |
|---|---|
| Loopback (`lo`) | Interface interna |
| IP | Endereço da máquina |
| `/24` | Máscara da rede |
| Ping | Teste de conectividade |
| TTL | Limite de saltos do pacote |
| RTT | Tempo da ida e volta |
