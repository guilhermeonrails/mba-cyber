## 1. O que é o Bash e o Primeiro Script
O **Bash** é um "interpretador de comandos". Quando você digita algo no terminal do Kali, o Bash lê, entende e executa. Um script nada mais é do que um arquivo de texto com vários desses comandos em sequência.

### Explicação
Todo script Bash deve começar com a "Shebang": `#!/bin/bash`. Ela avisa ao Linux: "Ei, use o Bash para ler este arquivo!".
Para rodar um script, você precisa de duas coisas:
1.  O arquivo salvo (ex: `ola.sh`).
2.  Permissão de execução (`chmod +x`).

### Exemplo Prático
```bash
# 1. Crie o arquivo
nano primeiro_script.sh

# 2. Digite isso dentro dele:
#!/bin/bash
echo "Hackeando o planeta... Mentira, estou apenas aprendendo Bash!"

# 3. Salve (Ctrl+O, Enter) e saia (Ctrl+X)
# 4. Dê permissão e execute:
chmod +x primeiro_script.sh
./primeiro_script.sh
```

**Mini resumo:**
Você aprendeu que um script é um arquivo de texto com superpoderes e que o comando `chmod +x` é a chave que destrava esses poderes.

## 2. Capturando Entradas do Usuário
Scripts úteis não são estáticos; eles interagem com você. Imagine um script que pergunta qual o alvo da vez.

### Explicação
Usamos o comando `read` para pausar o script e esperar que o usuário digite algo. O que for digitado fica guardado em uma variável para usarmos depois.

### Exemplo Prático
```bash
#!/bin/bash

echo "Qual é o seu nome, Recruta?"
read nome

echo "Bem-vindo ao Kali Linux, $nome! Qual IP vamos analisar hoje?"
read alvo

echo "Preparando ferramentas para o alvo: $alvo..."
```

**Mini resumo:**
O comando `read` permite que seus scripts se tornem dinâmicos, aceitando nomes, IPs ou qualquer informação em tempo real.

## 3. Scanner de Portas Simples (Netcat)
Em vez de usar ferramentas complexas, vamos criar nosso próprio mini-scanner de portas usando o comando `nc` (Netcat), que já vem no Kali.

### Explicação
O Netcat (`nc`) pode testar se uma porta está aberta. Usamos a flag `-z` (apenas scan) e `-v` (verboso/detalhado). Vamos unir isso ao que aprendemos de variáveis.

### Exemplo Prático
```bash
#!/bin/bash

echo "--- MINI PORT SCANNER ---"
echo "Digite o IP do alvo:"
read ip

echo "Escaneando portas comuns (80, 443, 22)..."

# Testando a porta 80 (HTTP)
nc -zv $ip 80

# Testando a porta 22 (SSH)
nc -zv $ip 22

echo "Scan finalizado para o host $ip"
```

**Mini resumo:**
Você criou uma ferramenta de automação real! Esse script economiza tempo ao testar múltiplas portas de um alvo automaticamente.

## 4. Comandos Internos Comuns do Bash (Built-ins)

| Comando    | Função                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------- |
| `:`        | Retorna 0 (verdadeiro)                                                                        |
| `.`        | Executa um script de shell                                                                    |
| `[[`       | Realiza um teste condicional                                                                  |
| `bg`       | Coloca um processo em segundo plano                                                           |
| `break`    | Sai do loop atual                                                                             |
| `cd`       | Muda o diretório                                                                              |
| `continue` | Continua para a próxima iteração do loop                                                      |
| `echo`     | Exibe os argumentos do comando                                                                |
| `eval`     | Avalia a expressão seguinte                                                                   |
| `exec`     | Executa um comando sem criar um novo processo, substituindo o atual                           |
| `exit`     | Encerra o shell                                                                               |
| `export`   | Torna uma variável ou função disponível para outros programas executados a partir deste shell |
| `fg`       | Traz um processo para o primeiro plano                                                        |
| `getopts`  | Processa argumentos de um script shell                                                        |
| `jobs`     | Lista processos em segundo plano                                                              |
| `pwd`      | Mostra o diretório atual                                                                      |
| `read`     | Lê uma linha da entrada padrão                                                                |
| `readonly` | Declara uma variável como somente leitura                                                     |
| `set`      | Lista todas as variáveis                                                                      |
| `shift`    | Move os parâmetros de entrada do script para a esquerda, descartando o primeiro               |
| `test`     | Avalia argumentos                                                                             |
| `times`    | Mostra os tempos de usuário e do sistema                                                      |
| `trap`     | Intercepta sinais para que o script possa tratá-los                                           |
| `type`     | Mostra como cada argumento seria interpretado como comando                                    |
| `umask`    | Altera as permissões padrão para novos arquivos                                               |
| `unset`    | Remove valores de uma variável ou função                                                      |
| `wait`     | Aguarda um processo em segundo plano terminar                                                 |
