# Explicação da Configuração de IP no Linux

A máscara de sub-rede, como o /24 (ou 255.255.255.0) do seu exemplo, é o que define qual parte de um endereço IP identifica a rede e qual parte identifica o dispositivo (host) específico dentro dessa rede. Ela funciona como um filtro: os bits marcados pela máscara dizem ao sistema que "esta vizinhança termina aqui", permitindo que o computador saiba se um destino está na mesma rede local ou se precisa enviar o pacote para um roteador (gateway) para alcançar uma rede externa. No caso do /24, os primeiros 24 bits (os três primeiros números do IP) são fixos para a rede, deixando os últimos 8 bits livres para endereçar até 254 aparelhos diferentes.

# Etapa 1 — Adicionando um IP

```text
Adicionando o IP 10.99.99.1/24 na interface lo
```

## Significado

Foi adicionado manualmente o IP:

```text
10.99.99.1
```

na interface:

```text
lo
```

(loopback)

---

## O que significa `/24`

Define o tamanho da rede.

Nesse caso:

```text
10.99.99.x
```

pertence à mesma rede.

---

# Etapa 2 — Verificando a interface

```text
1: lo: <LOOPBACK,UP,LOWER_UP>
```

## Significado

- `lo` → interface de loopback
- usada para comunicação interna
- `UP` → interface ativa

---

```text
inet 127.0.0.1/8
```

## Significado

IP padrão do loopback.

Representa:
> o próprio computador

---

```text
inet6 ::1/128
```

Versão IPv6 do loopback.

---

# Observação Importante

O novo IP:

```text
10.99.99.1
```

não apareceu na saída.

Isso indica que:
- o IP pode não ter sido adicionado corretamente
OU
- o comando falhou
OU
- a interface não atualizou

# Etapa 3 — Teste com Ping

```text
PING 10.99.99.1
```

O sistema tentou:
> enviar pacotes para o novo IP

---

# Resultado

```text
2 packets transmitted, 0 received
```

## Significado

- 2 pacotes enviados
- nenhuma resposta recebida

---

```text
100% packet loss
```

## Significado

Falha total na comunicação.

O IP:
> não respondeu ao ping

---

# O que isso sugere

Muito provavelmente:
- o IP não foi realmente configurado
OU
- a configuração falhou

Porque:
- se o IP estivesse ativo no loopback
- o ping deveria responder imediatamente

---

# Etapa 4 — Limpando a Configuração

```text
removendo o IP
```

O sistema removeu a configuração temporária da interface.

---

# Conceitos Importantes

| Termo | Significado |
|---|---|
| Loopback (`lo`) | Interface interna |
| IP | Endereço da máquina |
| `/24` | Máscara/tamanho da rede |
| Ping | Teste de conectividade |
| Packet loss | Perda de pacotes |

---

# Fluxo Esperado

Se o IP tivesse sido configurado corretamente:

```text
Seu PC
↓
10.99.99.1
↓
Resposta imediata
```

Mas como houve:

```text
100% packet loss
```

o endereço provavelmente:
- não existia na interface
- ou não estava ativo
