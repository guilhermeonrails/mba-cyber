# cron

### 1. Teste o comando manualmente

Antes de automatizar, valide no terminal:

```bash
ping -c 4 google.com
```

* `-c 4` → envia 4 pacotes e encerra (importante para o cron não ficar rodando indefinidamente)

---

### 2. Edite o crontab

Abra o agendador:

```bash
crontab -e
```

---

### 3. Adicione a tarefa

Exemplo: executar o ping **a cada 5 minutos**:

```bash
*/5 * * * * ping -c 4 google.com >> /home/kali/ping.log 2>&1
```

#### Explicação:

* `*/5 * * * *` → a cada 5 minutos
* Os **5 asteriscos (`* * * * *`)** representam, nesta ordem:

  1. Minuto (0–59)
  2. Hora (0–23)
  3. Dia do mês (1–31)
  4. Mês (1–12)
  5. Dia da semana (0–7, onde 0 e 7 = domingo)
* Quando usamos `*`, significa “qualquer valor” para aquele campo
* `*/5` no primeiro campo significa “a cada 5 minutos”
* `ping -c 4 google.com` → executa o ping
* `>> /home/kali/ping.log` → salva a saída em um arquivo
* `2>&1` → captura erros também

---

### 4. Outras opções úteis

* **A cada 1 minuto:**

```bash
* * * * * ping -c 2 google.com >> /home/kali/ping.log 2>&1
```

* **A cada hora:**

```bash
0 * * * * ping -c 4 google.com >> /home/kali/ping.log 2>&1
```

---

### 5. Dica importante

O `cron` usa um ambiente mais limitado. Para evitar problemas, use o caminho completo do comando:

```bash
*/5 * * * * /bin/ping -c 4 google.com >> /home/kali/ping.log 2>&1
```

Você pode descobrir o caminho com:

```bash
which ping
```
