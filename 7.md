# cron

### 1. Teste o comando manualmente

Antes de automatizar, valide no terminal:

```bash
ping -c 4 google.com
```

* `-c 4` → envia 4 pacotes e encerra (importante para o cron não ficar rodando indefinidamente)

---

### 2. Edite o crontab

Abra o agendador:

```bash
crontab -e
```

---

### 3. Adicione a tarefa

Exemplo: executar o ping **a cada 5 minutos**:

```bash
*/5 * * * * ping -c 4 google.com >> /home/kali/ping.log 2>&1
```

#### Explicação:

* `*/5 * * * *` → a cada 5 minutos

* Os **5 asteriscos (`* * * * *`)** representam, nesta ordem:

  1. Minuto (0–59)
  2. Hora (0–23)
  3. Dia do mês (1–31)
  4. Mês (1–12)
  5. Dia da semana (0–7, onde 0 e 7 = domingo)

* Quando usamos `*`, significa “qualquer valor” para aquele campo

* `*/5` no primeiro campo significa “a cada 5 minutos”

* `ping -c 4 google.com` → executa o ping

* `>> /home/kali/ping.log` → salva a saída em um arquivo

* `2>&1` → captura erros também

---

### 4. Inicie o serviço do cron

Em alguns ambientes (principalmente containers), o `cron` não inicia automaticamente. Nesse caso, inicie manualmente:

```bash
service cron start
```

Saída esperada:

```
┌──(root㉿783995eff962)-[/workspace]
└─# service cron start
Starting periodic command scheduler: cron.
```

---

### 5. Como parar o cron

Se você quiser interromper o serviço:

```bash
service cron stop
```

Isso irá parar completamente o agendador — nenhum job será executado enquanto ele estiver parado.

---

### 6. Outras opções úteis

* **A cada 1 minuto:**

```bash
* * * * * ping -c 2 google.com >> /home/kali/ping.log 2>&1
```

* **A cada hora:**

```bash
0 * * * * ping -c 4 google.com >> /home/kali/ping.log 2>&1
```

---

### 7. Dica importante

O `cron` usa um ambiente mais limitado. Para evitar problemas, use o caminho completo do comando:

```bash
*/5 * * * * /bin/ping -c 4 google.com >> /home/kali/ping.log 2>&1
```


---

Se quiser ir além, também dá para **remover jobs específicos** (`crontab -e`) ou limpar tudo com `crontab -r`.

Sim — você consegue usar o **Vim em vez do Nano** para editar o crontab. O editor que abre com `crontab -e` depende da variável de ambiente `EDITOR` (ou `VISUAL`).

---

## ✔️ Forma rápida (temporária)

Execute:

```bash
EDITOR=vim crontab -e
```

Isso abre o crontab no **Vim apenas nessa execução**.

---

## ✔️ Tornar o Vim padrão (recomendado)

Defina permanentemente:

```bash
export EDITOR=vim
```

Se quiser persistir entre sessões, adicione no seu `~/.bashrc`:

```bash
echo 'export EDITOR=vim' >> ~/.bashrc
source ~/.bashrc
```

---

## ✔️ Alternativa no Debian/Kali

Também pode usar o sistema de alternativas:

```bash
update-alternatives --config editor
```

E escolher o `vim` na lista.
