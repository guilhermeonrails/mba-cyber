O que é o Modelo OSI?

O modelo Open Systems Interconnection (OSI) é um modelo conceitual, criado pela ISO em 1984, que descreve as sete camadas que os sistemas de computadores usam para se comunicar através de uma rede.

Embora a Internet moderna use o modelo TCP/IP, o modelo OSI continua sendo a referência padrão para entender como as redes funcionam e para diagnosticar problemas de comunicação.

"O objetivo é permitir que sistemas diferentes se comuniquem, independentemente da sua arquitetura interna."

Detalhamento das Camadas

Camada 7

Aplicação (Application)

Esta é a única camada que interage diretamente com os dados do usuário. Software de aplicação como navegadores web e clientes de e-mail dependem da camada de aplicação para iniciar comunicações.

Protocolos: HTTP, SMTP, FTP, DNS
PDU: Dados
Exemplo: Navegador Chrome
Camada 6

Apresentação (Presentation)

Responsável pela "tradução", compressão e criptografia de dados. Ela garante que os dados enviados por um sistema possam ser lidos por outro.

Função: Criptografia SSL/TLS
PDU: Dados
Formatos: JPEG, MPEG, GIF, ASCII
Camada 5

Sessão (Session)

Esta camada gerencia as sessões de comunicação entre dispositivos. Ela abre, gerencia e encerra conversas entre aplicações.

Função: Controle de Diálogo
PDU: Dados
Protocolos: NetBIOS, RPC, SOCKS
Camada 4

Transporte (Transport)

Responsável pela comunicação ponta a ponta. Ela controla o fluxo de dados, a correção de erros e a segmentação de mensagens longas.

Protocolos: TCP, UDP
PDU: Segmento / Datagrama
Endereçamento: Portas (Ex: 80, 443)
Camada 3

Rede (Network)

Responsável por facilitar a transferência de dados entre redes diferentes. Determina o melhor caminho físico para os dados chegarem ao destino (Roteamento).

Protocolos: IP (IPv4, IPv6), ICMP
PDU: Pacote
Hardware: Roteador
Camada 2

Enlace de Dados (Data Link)

Responsável pela transferência de dados entre nós na mesma rede local. Define como os dados são formatados para transmissão.

Protocolos: Ethernet, Wi-Fi, PPP
PDU: Quadro (Frame)
Hardware: Switch, Bridge
Camada 1

Física (Physical)

Envolve o hardware físico real, como cabos e conectores. Transmite os fluxos de bits brutos sobre um meio físico.

Meios: Cabos de Cobre, Fibra, Ondas de Rádio
PDU: Bits
Hardware: Hub, Repetidor

O Processo de Encapsulamento

Conforme os dados descem da camada de Aplicação até a Física, cada camada adiciona informações de controle (headers/trailers). Esse processo é chamado de Encapsulamento. No destino, ocorre o Desencapsulamento.
