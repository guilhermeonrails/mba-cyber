## 🧩 1. Desafio: Organizando arquivos 

No terminal:

```bash
vim organizar.sh
```

Agora pressione:

```
i
```

(para entrar no modo de inserção)

Cole o conteúdo abaixo:

```bash
#!/bin/bash

# Criar diretórios
mkdir -p csvs pdfs imagens

# Mover arquivos por extensão
mv *.csv csvs/ 2>/dev/null
mv *.pdf pdfs/ 2>/dev/null
mv *.png imagens/ 2>/dev/null
```

---

## 💾 2. Salvar e sair do `vim`

Pressione:

```
ESC
```

Depois digite:

```
:wq
```

e pressione **Enter**

---

## ⚙️ 3. Tornar executável

```bash
chmod +x organizar.sh
```

---

## ▶️ 4. Executar

```bash
./organizar.sh
```

---

## 🧠 Atualizando o script (versão mais inteligente)

Abra novamente:

```bash
vim organizar.sh
```

Pressione `i` e substitua pelo código abaixo:

```bash
#!/bin/bash

for file in *.*; do
    ext="${file##*.}"

    case "$ext" in
        csv)
            dir="csvs"
            ;;
        pdf)
            dir="pdfs"
            ;;
        png)
            dir="imagens"
            ;;
        *)
            continue
            ;;
    esac

    mkdir -p "$dir"
    mv "$file" "$dir/"
done
```

Salvar novamente:

```
ESC
:wq
```
