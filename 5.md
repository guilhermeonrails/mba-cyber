# Explicação do IPv6

Essa atividade mostra:
- como visualizar endereços IPv6
- como testar conectividade IPv6
- como funciona o localhost no IPv6

---

# Etapa 1 — Visualizando Endereços IPv6

```text
inet6 ::1/128
```

## Significado

Esse é o endereço IPv6 da interface loopback.

O endereço:

```text
::1
```

é o equivalente ao:

```text
127.0.0.1
```

do IPv4.

Representa:
> o próprio computador

---

# Interface `lo`

```text
1: lo
```

## Significado

- interface de loopback
- usada para comunicação interna
- computador falando consigo mesmo

---

# O que significa `/128`

```text
::1/128
```

No IPv6:
- `/128` representa um único endereço
- equivalente a:
  > "somente este host"

---

# `scope host`

```text
scope host
```

Significa:
> o endereço é válido apenas dentro da própria máquina.

---

# Etapa 2 — Testando Comunicação IPv6

```text
PING ::1
```

O sistema enviou pacotes para:
> ele mesmo usando IPv6

---

# Resposta do Ping

```text
64 bytes from ::1
```

## Significado

O IPv6 respondeu corretamente.

Isso mostra que:
- a pilha IPv6 está funcionando
- o loopback IPv6 está ativo

---

```text
icmp_seq=1
icmp_seq=2
icmp_seq=3
```

- sequência dos pacotes enviados

---

```text
ttl=64
```

TTL = quantidade máxima de saltos do pacote.

Como a comunicação foi local:
- praticamente não houve alteração

---

```text
time=0.056 ms
```

Tempo extremamente rápido porque:
> a comunicação aconteceu dentro do próprio computador.

---

# Estatísticas do Ping

```text
3 packets transmitted, 3 received
```

## Significado

- 3 pacotes enviados
- 3 respostas recebidas

Conectividade perfeita.

---

```text
0% packet loss
```

## Significado

Nenhuma perda de pacotes.

---

# RTT (Tempo de Resposta)

```text
rtt min/avg/max
```

Mostra:
- menor tempo
- média
- maior tempo da comunicação

---

# Diferença entre IPv4 e IPv6

| IPv4 | IPv6 |
|---|---|
| `127.0.0.1` | `::1` |
| 32 bits | 128 bits |
| formato decimal | formato hexadecimal |
| menos endereços | quantidade enorme de endereços |

---

# Navegador e IPv6

```text
http://[2001:db8::1]/
```

## Significado

No navegador:
- endereços IPv6 precisam ficar entre colchetes

Porque:
- o IPv6 usa `:`
- e isso poderia confundir a URL

---

# Fluxo da Comunicação

```text
Seu PC
↓
::1
↓
Resposta imediata
↓
Seu PC
```

Toda a comunicação aconteceu:
> dentro da própria máquina

---

# Conceitos Importantes

| Termo | Significado |
|---|---|
| IPv6 | Nova versão do protocolo IP |
| `::1` | Localhost IPv6 |
| Loopback | Comunicação interna |
| `/128` | Endereço único |
| Ping | Teste de conectividade |
| RTT | Tempo da ida e volta |
