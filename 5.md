## 🧩 1. Desafio: Organizando arquivos 

No terminal:

```bash
vim organizar.sh
```

Agora pressione:

```
i
```

(para entrar no modo de inserção)

Cole o conteúdo abaixo:

```bash
#!/bin/bash

# Criar diretórios
mkdir -p csvs pdfs imagens

# Mover arquivos por extensão
mv *.csv csvs/ 
mv *.pdf pdfs/ 
mv *.png imagens/
```

🔎 Detalhes importantes:
*.csv, *.pdf, *.png → globbing (expansão de arquivos)
2>/dev/null → evita erro caso não existam arquivos daquele tipo

## 🧠 Atualizando o script (versão mais inteligente)

Abra novamente:

```bash
vim organizar.sh
```

Pressione `i` e substitua pelo código abaixo:

```bash
#!/bin/bash

for file in *.*; do
    ext="${file##*.}"

    case "$ext" in
        csv)
            dir="csvs"
            ;;
        pdf)
            dir="pdfs"
            ;;
        png)
            dir="imagens"
            ;;
        *)
            continue
            ;;
    esac

    mkdir -p "$dir"
    mv "$file" "$dir/"
done
```

Salvar novamente:

```
ESC
:wq
```
